# ReUnity Self-Hosting Deployment Guide

Deploy ReUnity on Railway with OpenAI API integration.

**Estimated Monthly Cost**: ~$55 (Railway ~$5-20, OpenAI ~$30-50 depending on usage)

---

## Prerequisites

1. [Railway Account](https://railway.app) (free tier available)
2. [OpenAI API Key](https://platform.openai.com/api-keys) with GPT-4o and DALL-E 3 access
3. Git installed locally
4. Node.js 22+ and pnpm installed (for local testing)

---

## Quick Start (5 minutes)

### Step 1: Deploy to Railway

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/template/reunity)

Or manually:

```bash
# Install Railway CLI
npm install -g @railway/cli

# Login to Railway
railway login

# Create new project
railway init

# Link to this directory
railway link
```

### Step 2: Add MySQL Database

1. In Railway dashboard, click **+ New**
2. Select **Database** → **MySQL**
3. Railway auto-generates `DATABASE_URL`

### Step 3: Configure Environment Variables

In Railway dashboard → **Variables**, add:

| Variable | Value | Required |
|----------|-------|----------|
| `OPENAI_API_KEY` | Your OpenAI API key (sk-proj-...) | Yes |
| `JWT_SECRET` | Random 64-char string | Yes |
| `NODE_ENV` | `production` | Yes |

Generate JWT_SECRET:
```bash
openssl rand -hex 32
```

### Step 4: Deploy

```bash
railway up
```

Or push to GitHub and connect the repo in Railway for auto-deploys.

## Detailed Setup

### Database Migration

After first deploy, run migrations:

```bash
# SSH into Railway
railway run pnpm db:push
```

### Custom Domain Setup

1. In Railway dashboard → **Settings** → **Domains**
2. Add your custom domain (e.g., `app.yourdomain.com`)
3. Add DNS records:

| Type | Name | Value |
|------|------|-------|
| CNAME | app | `your-project.up.railway.app` |

4. Wait for SSL certificate (automatic, ~5 minutes)

### S3 Storage (Optional)

For file uploads, add these variables:

```
AWS_ACCESS_KEY_ID=your-key
AWS_SECRET_ACCESS_KEY=your-secret
AWS_REGION=us-east-1
S3_BUCKET=your-bucket-name
```

## Environment Variables Reference

### Required

| Variable | Description |
|----------|-------------|
| `OPENAI_API_KEY` | OpenAI API key for GPT-4o and DALL-E 3 |
| `DATABASE_URL` | MySQL connection string (auto-generated by Railway) |
| `JWT_SECRET` | 64-character random string for session signing |
| `NODE_ENV` | Set to `production` |

### Optional

| Variable | Description | Default |
|----------|-------------|---------|
| `PORT` | Server port | 3000 |
| `VITE_APP_TITLE` | Application title | ReUnity |
| `VITE_APP_LOGO` | Logo URL | /logo.svg |

## Local Development

```bash
# Clone the repository
git clone https://github.com/yourusername/reunity-app.git
cd reunity-app

# Install dependencies
pnpm install

# Copy environment template
cp docs/env.example.txt .env
# Edit .env with your values

# Run database migrations
pnpm db:push

# Start development server
pnpm dev
```

## Troubleshooting

### "OPENAI_API_KEY is not configured"

Ensure `OPENAI_API_KEY` is set in Railway Variables. The key should start with `sk-proj-`.

### Database connection failed

1. Check `DATABASE_URL` is set
2. Ensure MySQL service is running in Railway
3. Try restarting the service

### Image generation fails

1. Verify your OpenAI account has DALL-E 3 access
2. Check API key has sufficient credits
3. Review Railway logs for specific errors

### Build fails

```bash
# Clear cache and rebuild
railway run pnpm install --force
railway up --force
```
